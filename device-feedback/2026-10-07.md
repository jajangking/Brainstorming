## D. Trigger env minimal (§17.1b)

Resep briefing TIDAK bisa dijalankan apa adanya — dua cacat bertingkat:

- Perintah persis briefing:
  `env -i APK_SCRIPT=trigger APK_PACKAGE=busybox fake-run <trigger> /bin`
  → **RC=1**, output:
  ```
  /data/data/com.termux/files/usr/bin/fake-run: line 20: HOME: unbound variable
  ```
  (`env -i` membuang `HOME`; `fake-run` memakai `set -u` → `$HOME` dipakai di
  baris 20–21 untuk `HOME_BASE`/`SHIM`.)
- Ditambah `HOME` + `PATH` → gagal lagi: `line 136: PREFIX: unbound variable`
  (jalur svsp mencari svsp di `"$PREFIX/bin"`).
- Bentuk yang bisa jalan: tambah `HOME`, `PATH`, `FAKE_SVSP`:
  `env -i HOME=$HOME PATH=$PREFIX/bin FAKE_SVSP=$PREFIX/bin/svsp APK_SCRIPT=trigger APK_PACKAGE=busybox fake-run <trigger> /bin`
  → **RC=127**, output:
  ```
  bin: applet not found
  ```
  (skrip trigger shebang `#!/bin/busybox sh` dieksekusi sebagai
  `busybox <path-skrip>` — argumen `sh` HILANG → busybox mengira itu applet).
- Variasi `--ldpreload` (jalur shim) → **RC=127** juga:
  ```
  probe-trigger: applet not found
  ```
- **Akar masalah ditemukan** (trace `bash -x fake-run`): `shebang_parse` dipanggil
  lewat `interp="$(shebang_parse "$host")"` → SUBSHELL → assignment `SBARGS=()`
  di dalam fungsi tidak pernah keluar ke shell induk → `${#SBARGS[@]}` = 0 →
  argumen shebang (`sh`) dibuang. Pemanggilan berbentuk `$(...)` ini **baru
  ditambahkan di commit `ce108b9`** ("… shebang exec + env-merge …") — regresi
  dari fix arena, bukan bug lama.
- Karena itu verifikasi langsung env-merge (inti §18.2b) tidak bisa lewat jalur
  ini. Pengganti yang lebih merepresentasikan kasus asli (anak apk yang
  `env -i` lalu exec skrip) saya jalankan lewat B: **trigger busybox sukses RC=0**
  — artinya env-merge UNTUK ANAK PROSES APK bekerja di jalur shim.
  (Uji `fake-run --ldpreload /bin/busybox env -i APK_SCRIPT=... /bin/sh probe.sh`
  memberi `FAKE_BASE=KOSONG` — dugaan: execve dari dalam libc musl tidak lewat
  PLT sehingga interposer tidak terpanggil; TIDAK diverifikasi lebih lanjut.)
- **rc=127 yang dulu (§17.1b) pada jalur apk-asli TIDAK terulang** (B sukses);
  rc=127 di sini murni karena resep/bagian fake-run di atas.
